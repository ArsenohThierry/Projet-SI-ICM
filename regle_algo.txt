 FOmba itondrana anle algo pour le choix de regime en fonction de l'objectif et du poids :
 Objectif PRISE_POIDS
 → Régime riche en viande/volaille (protéines)
 → variation_poids la plus haute (+ de kg/semaine)
 → ORDER BY (variation_poids * 0.7) - (montant * 0.3) DESC
 On veut variation_poids MAX et montant MIN

 Objectif PERTE_POIDS
 → Régime riche en poisson (moins calorique)
 → variation_poids la plus basse (- de kg/semaine)
 → ORDER BY (ABS(variation_poids) * 0.7) - (montant * 0.3) DESC
 On veut variation_poids MIN et montant MIN

 Objectif IMC_IDEAL
 → Régime équilibré entre les 3
 → variation_poids modérée
 → ORDER BY (ABS(variation_poids) * 0.7) - (montant * 0.3) ASC
 On veut variation_poids proche de 0 et montant MIN

 score = (variation_poids x poids_efficacite) - (montant x poids_cout)
 score = (variation_poids x 0.7) - (montant x 0.3)



 Le problème
 IMC actuel = 27 (surpoids)
 IMC idéal  = 18.5 à 25
 Objectif choisi = IMC_IDEAL

 → La personne doit D'ABORD perdre du poids avant d'atteindre l'équilibre
 Solution — Calculer l'écart IMC
 IMC = poids / (taille_m)²
 IMC_ideal_cible = 22  (milieu de la fourchette 18.5-25)

 écart = IMC_actuel - IMC_ideal_cible
 Si IMC > 25 (surpoids)
 → écart positif
 → Appliquer logique PERTE_POIDS d'abord
 → ORDER BY (ABS(variation_poids) * 0.7) - (montant * 0.3) DESC
 Si IMC < 18.5 (insuffisance)
 → écart négatif
 → Appliquer logique PRISE_POIDS d'abord
 → ORDER BY (variation_poids * 0.7) - (montant * 0.3) DESC
 Si 18.5 ≤ IMC ≤ 25 (déjà dans la zone)
 → Appliquer logique IMC_IDEAL (maintien)
 → ORDER BY (ABS(variation_poids) * 0.7) - (montant * 0.3) ASC
 Algorithme complet
 1. Calculer IMC = poids / (taille_m)²

 2. SI objectif = IMC_IDEAL
       SI IMC > 25
           → utiliser formule PERTE_POIDS
           → afficher message "Vous devez d'abord perdre X kg"
       SINON SI IMC < 18.5
           → utiliser formule PRISE_POIDS
           → afficher message "Vous devez d'abord gagner X kg"
       SINON
           → utiliser formule IMC_IDEAL
           → afficher message "Vous êtes proche de votre IMC idéal !"

 3. Calculer le poids cible
    poids_cible = IMC_ideal_cible x (taille_m)²
    poids_a_perdre/gagner = poids_actuel - poids_cible
